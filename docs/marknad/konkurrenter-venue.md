## Per aktör

**Lega Online** (Multinet, Stockholm). Rumsuthyrning snarare än sales & catering. Portalen tar emot förfrågningar. Kökslistor med specialkost. Brett ekonomiintegrationsstöd. Logotyper: Ideon, WTC Malmö, Sensus, Convendum, Akademiska Hus.

**VisBook** (Visit Group, Göteborg). Hotell-PMS med konferensmodul (paket med logi, middag, aktiviteter). ≈800 kunder 2019. Referenser: Hackholmssund, Trosa Stadshotell, Nääs Fabriker. Passar dåligt för venues utan logi.

**Caspeco** (Uppsala, 280 anställda, 6 500 kunder). Restaurangsystem; bokningsmodulen hanterar event med förbeställda menyval, Swish/kort, deposition, offert → faktura och Fortnox. Konferens marknadsförs inte som produkt. Viktig att bevaka: sitter redan hos svenska restauranger.

**MeetingPackage** (Helsingfors, $4,6M Series A 2023). Offert och direktbokning för hotellmöten. Scandic, Strawberry. Ingen egen CRM, ingen kökslogik bekräftad.

**Proposales** (Sverige). Offertlager för hotell. Stripe-betalning (1,2 % avgift), ingen Swish/Fortnox hittad. Elite Hotels (40+ hotell), Strawberry.

**Event Temple** (Vancouver). Fullständigt S&C för hotell. Strawberry 174 hotell med Mews-integration. Från $249/mån, årsavtal.

**Mews Events** (Amsterdam). Köpte Quotelo 2024. Event-modul kräver Mews PMS. Bara EU/APAC.

**Amadeus Delphi / Oracle OPERA SEM.** Enterprise S&C för stora hotell. Klagomål: daterat UI, dubbelinmatning, svag rapportering.

**Momentus** (tidigare Ungerboeck). Arenor och mässor. Inga nordiska kunder hittade.

**Venjue** (Odense, 1–10 anställda). Närmast Okazis koncept: allergener per rätt och gäst som slår igenom i köksorder, bordsplacering, Stripe-förskott, bekräftad bokning blir fakturautkast. Bara danska integrationer (e-conomic, Dinero, Billy).

**Tripleseat / Perfect Venue** (USA). Fullständiga venue-flöden för restauranger och eventlokaler. Ingen nordisk närvaro.

**Agendo / BokaMera.** Generisk slotbokning med Swish och Fortnox/Visma. Prisgolv för enkel rumsbokning.

**Övriga att känna till:** Bookvisit (Göteborg, hotellbokningsmotor), Venuu (marknadsplats SE/FI/DK, möjlig leadkanal), Timetomeet (Göteborg, marknadsplats + bokningsmotor), Event Logic (DK), Anolla, Boka.se.

## World of Volvo
- System okänt publikt (kontaktformulär, Teamtailor för rekrytering, Tickster för biljetter).
- Maten levereras av Götaplatsgruppen (Ceno), som "lagar all mat" till konferenserna.
- Paket 590–1 016 kr/person. Upp till ≈1 100 personer, 7 konferensrum.

## Luckor
1. Ingen svensk SaaS kopplar förfrågan → offert → möblering → meny med allergier per deltagare → köksorder → förskott/faktura med Swish + Fortnox/Visma.
2. Hotellen är försörjda; venues utan hotell har Lega eller generiska verktyg.
3. Allergier per deltagare: bara Venjue bekräftat.
4. Köksorder till extern partner: ingen marknadsför det.
5. Direktbokning med betalning för små möten saknas hos Lega.
6. Publicerade priser och gratisnivå: bara Venjue, Perfect Venue och generiska verktyg.
